# E-Commerce KE — Android Wrapper

A Flutter Android application that wraps the [E-Commerce Store KE](https://ecommerce-rails-app.onrender.com) Rails backend in a native WebView shell, ready for Google Play Store distribution.

## Features
- 🛍️ Full shopping experience (products, cart, checkout)
- 💳 Stripe / M-Pesa / COD / Bank Transfer payments
- 🔐 Login with Google & GitHub OAuth
- 📦 Order tracking & PDF invoices
- ❤️ Wishlist, comparisons, reviews
- 📶 Offline detection with branded error screen
- 🌓 Light & dark mode support

## Package Name
`com.larrykj.ecommerce_store`

## Build Requirements
- Flutter 3.12+
- Android SDK API 21+ (minSdk)
- Android SDK API 35 (targetSdk)

## Quick Start

```bash
flutter pub get
flutter run
```
